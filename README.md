# Visual Captioning

Visual Captioning là một dự án tạo chú thích tự động cho hình ảnh bằng cách sử dụng các kỹ thuật học sâu. Dự án bao gồm hai phần chính:

* **algorithms**: chứa các file notebook dùng để xử lý dữ liệu, huấn luyện và đánh giá mô hình sinh caption từ ảnh.
* **application**: chứa mã nguồn của ứng dụng web cho phép người dùng tải lên hình ảnh và nhận về chú thích tương ứng do mô hình sinh ra.

Dự án hướng đến việc kết hợp giữa mô hình học sâu và giao diện trực quan để mang lại trải nghiệm đơn giản và hiệu quả cho người dùng khi tạo chú thích ảnh.
